# Golden Raspberry Awards Dashboard

![Angular](https://img.shields.io/badge/Angular-19-DD0031?logo=angular&logoColor=white)

An Angular dashboard for exploring Golden Raspberry Awards results. It highlights years with multiple winners, leading studios, producer award intervals, and movie results by year.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200` in a browser. Movie data is requested from the configured backend endpoint in the movie service.
